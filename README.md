# Naman Bagdiya - Portfolio Website

A modern, responsive portfolio website built with Next.js, TypeScript, and Tailwind CSS, featuring smooth animations and interactive elements.

## 🚀 Features

- **Responsive Design**: Fully responsive across all devices
- **Modern UI/UX**: Clean, professional design with smooth animations
- **Interactive Elements**: Hover effects, animated cursors, and dynamic content
- **Performance Optimized**: Fast loading with optimized animations
- **Accessibility**: Built with accessibility best practices
- **SEO Friendly**: Optimized meta tags and semantic HTML

## 🛠️ Tech Stack

- **Framework**: Next.js 14
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **UI Components**: Custom components with Radix UI
- **Icons**: Lucide React

## 📱 Sections

- **Hero**: Dynamic typing animation and social links
- **About**: Personal introduction and status information
- **Skills**: Interactive skill levels and categories
- **Projects**: Showcase of web development projects
- **Contact**: Multiple ways to get in touch

## 🎨 Design Features

- **Neon Theme**: Cyberpunk-inspired design with cyan and lime accents
- **Smooth Animations**: Framer Motion powered transitions
- **Interactive Cursor**: Custom neon cursor effect
- **Scroll Progress**: Visual scroll indicator
- **Loading Screen**: Animated loading experience

## 🚀 Getting Started

1. Clone the repository:
```bash
git clone <repository-url>
cd Portfolio-NEXT
```

2. Install dependencies:
```bash
npm install
# or
pnpm install
```

3. Run the development server:
```bash
npm run dev
# or
pnpm dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
